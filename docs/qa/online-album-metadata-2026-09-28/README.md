# 自动补全专辑信息验证 · 2026-09-28

管理员在“补充专辑信息”中选择“自动补全”，从 MusicBrainz 按专辑查询。结果为表单草稿，保存后才写入独立覆盖表，音乐文件继续只读。

## 自动检查

- `npm run typecheck`、`npm run build`、`git diff --check` 通过。
- `npm test`：32 个测试文件、497 项测试通过。
- 新增匹配与安全覆盖：查询转义、艺人/曲目数/碟数/年份核对、多发行版不自动选择、搜索截断、不从最早发行日期推断当前版本年份、未知艺人、来源失败、空结果缓存过期、并发合并、统一限流、超时、响应体上限、来源域名限制、关闭在线能力后不发请求。
- API 验证：管理员/普通账号/未登录、跨域来源保护、参数验证、查找前后版本冲突、查询不写入专辑覆盖值或源标签。
- 表单逻辑验证：保留已有值、保留查询期间修改后又清空的字段、切换候选时同步更新自动填入字段、保留之后的手动编辑。
- `SCAN_ONLINE_METADATA=false` 可以只开启按需查询，扫描器不发逐曲补全请求。
