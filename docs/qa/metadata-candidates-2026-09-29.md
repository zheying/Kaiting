# 专辑信息候选展示验收 · 2026-09-29

## 交付行为

- 打开“编辑专辑信息”时读取在线发行参考，保留手动输入与后台高置信自动补全。
- 候选展示发行日期、地区、介质、碟数、曲目数、艺人、流派及 MusicBrainz 来源链接。
- 标明本地与候选的曲目数、碟数、年份、艺人等差异，不把未经核实的参考标成可信结果。
- “采用此版本”仅填入年份和流派草稿；缺失字段保留已有输入，点击保存才生效。关闭或取消不保存。
- 迟到结果不覆盖输入；查询失败、无候选或关闭在线能力时仍可手动编辑。查询版本冲突保留草稿，明确重新载入后才替换。
- 默认显示前两个候选，可展开其余版本；长列表单独滚动，手机端保留可达的保存按钮。
