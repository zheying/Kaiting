# 后台专辑补全与人工修正验收

## 行为

- 启用在线能力后，后台专辑补全默认开启，仍可显式关闭。初次扫描、新增专辑后的增量扫描及重新扫描完成后自动查询，可靠的缺失年份、流派直接保存，不依赖页面、弹窗或保存按钮。
- 保留完整扫描、唯一正式发行、名称/艺人/曲目数/碟数/年份核对、结果完整性及版本保护，不为提高补全数量而放宽条件。不能确认的信息保持空白。
- 弹窗改为“编辑专辑信息”，删除按需查询、候选选择和“自动补全”按钮。信息完整的专辑卡片也保留编辑入口，自动信息显示来源。
- 人工修正或恢复扫描值后保留人工管理标记，后台不会覆盖；冲突时保留草稿，明确重新载入后才替换表单。
