# 扫描后后台补齐专辑信息 · 2026-09-28

> 隐私说明：环境地址和路径已替换为示例；原始验收附件在仓库外私有保存，不随仓库发布。

用户选择：扫描后后台自动补齐曲库，高置信结果直接保存。

## 实现

- 完整、无文件错误且没有保留缺失索引的扫描结束后，独立启动串行查询；扫描结果不等待网络。服务启动时也检查已完整扫描的现有库。
- 沿用 MusicBrainz 发行匹配：专辑名称、艺人、曲目数、碟数、已有年份全部符合，唯一正式发行，搜索未截断且详情完整时，直接保存缺失年份、流派。
- 自动补全独立保存在 `album_metadata_enrichment`，记录发行 ID 和匹配时间。扫描标签和人工设置优先；管理员保存或恢复后，该专辑转为人工管理，后台不再改动。
- 新扫描、切换目录、曲目变化及人工修改使旧查询失效。关闭服务后不再写入结果或缓存。连续三次查询失败暂停，最多在 1 分钟、5 分钟后各重试一次。
- 专辑列表通过轻量曲库版本通知自动更新，不重载页面；专辑信息弹窗显示后台补全状态和来源。查询不上传文件、路径或账号，音乐目录保持只读。
