# 移动播放页收起修复验收

> 隐私说明：环境地址和路径已替换为示例；原始验收附件在仓库外私有保存，不随仓库发布。

日期：2026-09-23。

用户反馈：393 × 852 视口中，点击全屏播放页顶部的收起按钮，底层页面跳变。

## 问题与修复

- 全屏样式原先将页面和应用容器限制为一屏高，导致长列表的滚动位置被压到零。移动端现在保留背景页面的自然高度。
- 滚动条消失、恢复时，背景宽度原先在 393 与 378 像素之间变化。现在为背景保留滚动条空间，并让播放页覆盖整个视口。
- 收起动画删除中途停顿的关键帧，按动画结束事件关闭页面；700 毫秒定时器仅作兜底。重复点击不会连续后退，减少动态效果偏好会跳过动画。
- 历史记录保存播放页的来源页面和滚动位置。背景异步加载时恢复位置，覆盖“专辑 → 播放页 → 艺人 → 浏览器返回 → 收起”的路径。
- 全屏可见时，背景控件暂时不可交互；音频元素保持挂载。没有当前歌曲时不会锁住首页。
