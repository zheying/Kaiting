# 播放器文字动效验收

> 隐私说明：环境地址和路径已替换为示例；原始验收附件在仓库外私有保存，不随仓库发布。

日期：2026-09-23。参考 [Apple Music](https://music.apple.com/cn/new) 公开试听播放器，范围为桌面胶囊的歌名及艺人/专辑信息区。

实测发现：超长文字整体滚动，短标题静止；副本间隔 28px、两端渐隐 15px；测得 350.40625px 位移 / 17.5203 秒，对应约 20px/s。一次自动滚动完成后停回开头。Apple 后续试听切换不稳定，未确认所有触发时序。本实现选择 1 秒起始停顿、每次一轮，鼠标重新进入可重播。

实现使用 ResizeObserver 测量实际文字宽度，无新增依赖。键盘聚焦时停止滚动并显示目标链接；视觉副本不增加焦点或朗读内容；遵循减少动态效果偏好。
