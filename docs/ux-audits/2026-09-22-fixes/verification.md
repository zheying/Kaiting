# UI 审计问题修复与验收

> 隐私说明：环境地址和路径已替换为示例；原始验收附件在仓库外私有保存，不随仓库发布。

日期：2026-09-22。修复已部署至 <http://192.0.2.10:3002>，镜像为 `music-library:2026-09-22-ui-fix`。正式容器健康状态为 `healthy`，原登录会话仍有效。

对应上一轮审计的 7 项改进均已实施：

1. 桌面播放页按可用高度限制封面，控制区保留空间；极矮窗口使用内部滚动。外层使用 `overflow:clip`，防止放大的背景导致焦点滚动把关闭按钮带出屏幕。
2. 底部和全屏进度条共用 `useSeekInput`。以交互开始时的 DOM 实际数值比较更改，避免整数 range 与浮点播放秒数的差异；Tab、Shift+Tab、普通失焦和未改变进度均不提交 seek。实际键盘或鼠标调整正常提交，切歌和取消丢弃未完成操作。
3. 缺少专辑艺人的歌曲按“精确父目录 + 专辑名”分组，多作曲者显示“多位艺人”；保留已有明确专辑艺人身份和多碟分组。歌曲 ID 不变，旧专辑链接唯一匹配时兼容，无需重新扫描。
4. 搜索顶部显示关键词及三类实际匹配数，通过按钮直接切换歌曲、专辑、艺人；不再显示全库总量和扫描状态。
5. 首页压缩标题区，把正常运行状态收为可展开详情；错误能展开文件名、完整路径和技术说明，并提供增量重试入口。
6. 取消删除歌单或按 Escape 后恢复删除按钮焦点；每首歌曲的播放与更多按钮名称包含歌名，焦点轮廓更明确。
7. 专辑卡补充首数和年份、长文字完整标题提示；详情缩小长标题、增加返回与艺人信息、移除重复专辑列；待播清单增加显式关闭按钮，并恢复触发按钮焦点。

- 待播清单关闭按钮可用，关闭后焦点返回“待播清单”。扫描错误详情可显示具体文件和路径；没有为 UI 验收重试扫描或改写曲库文件。
