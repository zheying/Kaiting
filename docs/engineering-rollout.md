# 音泊原型落地与正式系统集成

> 隐私说明：环境地址和路径已替换为示例；原始验收附件在仓库外私有保存，不随仓库发布。

设计基线：`ff1b7a5` 中的 `prototypes/listening-room`。正式客户端沿用原型组件、CSS、图标、响应式断点和交互；原型保留为独立对照，不接入真实数据。

## 不变量

音乐目录保持只读；所有持久状态位于 DATA_DIR。路径仍通过 safeRealPath。AAC M4A 直传、ALAC M4A 转码。目录切换保留原索引和个人收藏，扫描清理保留原有挂载与遍历保护。真实账号和凭据由服务端校验，不以页面隐藏代替权限控制。

## 实现范围

| 模块 | 正式实现 |
| --- | --- |
| 视觉与布局 | 原型的 11 份 CSS、favicon、Canvas 动画原样复用；保留玻璃登录框、侧栏、响应式布局、胶囊播放器、弹窗和状态组件。 |
| 登录与账号 | 服务端 scrypt 密码哈希、可撤销会话、角色校验、首次改密、个人资料、会话管理、账号创建/重置/停用。创建账号时由服务端随机生成 12–22 位临时密码。 |
| 个人数据 | 收藏、歌单、歌曲顺序、主题、播放队列、进度及音量按账号保存；歌单创建支持幂等重试，排序校验版本冲突。 |
| 音乐目录 | 浏览部署允许的目录，选择后自动扫描；后台进度、停止、完整/部分成功、空目录及失败状态来自真实服务。更换目录会停止播放并清空当前队列。 |
| 曲库 | 真实专辑、艺人、歌曲、搜索、格式筛选、多碟分组、封面拼图和按需显示更多行；保留旧专辑及搜索链接兼容。 |
| 播放 | 真实 Audio 播放、直传与 FFmpeg 转码、进度定位、音量、随机/循环、系统媒体控件和实际 LRC 歌词；加载、缺失、断线与解码失败使用原型反馈。 |

正式客户端不再导入原型的 `library.json`、演示账号或模拟歌词；独立原型继续保留用于设计对照。为真实使用调整了少量说明文字，例如“查看演示”改为“登录帮助”，存储说明改为服务端数据目录。

## 验收环境与交付边界

本地正式构建使用独立临时 DATA_DIR 和生成的静音音频进行验收；视觉对照的标题与封面来自原型样本，经正式数据库/API 读取。实际扫描使用独立 AAC 文件与空目录。本地验收未改动用户音乐目录或现有运行数据。

同日按用户要求已部署到 `192.0.2.10:3002`，完成正式数据备份、账号迁移校验和真实 NAS 音频读取/转码验证。详见 [正式部署记录](deployments/2026-09-28-engineering/README.md)。

随后补齐扫描完成提示，并移除首页常驻的历史完成横条；原型结果页和 CSS 保持不变。433 项测试通过，修复已更新至同一 Docker 服务，见 [扫描反馈修复记录](deployments/2026-09-28-scan-feedback/README.md)。

发布时应按 README 先备份原 DATA_DIR，再配置 ADMIN_PASSWORD、COOKIE_SECRET、音乐目录与 Cookie 传输方式。管理员初始密码只在首次建立账号时使用；旧会话需要重新登录，旧浏览器本地播放偏好不自动导入。

尚未在实体 iOS/Android 设备或超大曲库上验收，也未验证第三方在线元数据服务的实时可用性。当前客户端分页取得完整元数据快照后在本地检索，超大曲库的内存和首次加载耗时仍需按实际规模评估。
