# 测试选择命令验收需求

此清单先于测试选择脚本编写。验证对象是开发者调用命令后的可见行为，不对脚本内部函数补单元测试，也不执行完整产品测试套件。

| 输入 / 失败方式 | 预期行为 |
| --- | --- |
| `npm test` 没有选择文件；只有 `-t` 参数 | 显示用法、非零退出，不启动 Vitest；旧 CI 不能误报通过 |
| 精确选择一个或多个现有测试文件 | 只选择这些文件；重复输入去重 |
| 文件路径拼错、目录路径、未知功能、未知选项 | 非零退出，不退回全量 |
| `--scope` 等无效选择方式 | 指向正确用法，不把选项值当成文件 |
| `unit` / `integration` / `prototype` | 层级和原型范围正确；unit 与 integration 不交叉且并集包含所有现有测试 |
| 单功能 / 多功能选择 | 集合正确、去重；不把原型测试加入无关生产功能 |
| `--list` 预览任何范围，包括 `all` / `ci` | 输出文件和拟执行参数；不导入测试模块、不启动 Vitest |
| `-t` 用例名称筛选 | 完整保留正则表达式，不经 shell 展开；无匹配不能通过 |
| 新测试未登记 / 登记文件被移动 | 提示维护清单并失败，不能静默漏测 |
| 原型命令 | 原型测试仍可运行，且仍属于显式全量 |
| 显式 `all` / `ci` | 包含所有测试，不接受缩减范围的额外参数；CI 固定禁用 `.only` 并输出 JUnit |
| CI 缺少 FFmpeg | 在执行前失败，避免现有真实转码测试通过 `skipIf` 静默跳过 |
| 实际运行一个小范围 | 运行 1 个 unit 文件和 1 个 integration 文件，保存 JSON 结果，核对文件和用例数量 |
| 子进程失败 | 将失败状态传回调用方；实际无匹配用例必须非零退出 |

复验入口：`npm run test:selection`。结果保存至 `artifacts/test-selection/`。目录在 Git 中忽略；本次验收摘要另保存在审查文档旁。浏览器端到端流程覆盖单独评估，本脚本验收不算产品 E2E。
