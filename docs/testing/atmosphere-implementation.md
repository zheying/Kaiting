# 氛围模式正式接入验收

范围：将已定稿的 22 种舞台灯光、自动编排、强度与色调、歌词、待播清单和浮窗交互接入正式音乐室。正式播放器继续负责播放、队列、转码 seek、音量、错误恢复和系统媒体控制；视图切换不创建播放器，不调用加载、暂停或 seek。

实现前确定的失败方式与预期：

- 普通页、氛围页、胶囊之间切换：同一正在播放的媒体元素、同一队列与时间线，没有额外 stream 请求、暂停或等待；暂停进入也保持暂停。
- AAC 直传与 ALAC 转码：灯光和歌词使用完整歌曲时钟，跳转后不沿用上一段的时间或重拍；切歌晚到的分析结果不得覆盖当前歌曲。
- 实时分析与声音输出：在原有播放手势中建立持久声音分析，进入氛围模式只订阅读数；音量与静音仍正常，静音不抹去音乐特征。退出视图释放画布而保留播放；退出账号释放声音资源。
- 编排 API：登录保护、源文件路径校验、只读解码、相同请求合并、并发与时长限制、缓存版本/源文件变化失效、损坏缓存重建、服务关闭中断解码。缓存只写 DATA_DIR，符号链接不能把缓存指回曲库。
- 分析慢、失败或不可用：音乐不等待分析，灯光使用实时声音；WebGL 不可用或丢失可降级，减少动态效果偏好生效。
- 界面：22 种灯光可选，灯具位置固定；歌词/队列进出不移动舞台和播放控制；手机保持操作空间，浮窗内部可操作、外侧关闭、Esc 按层关闭。

验证使用生产构建、Playwright 管理的 Chromium、临时曲库和独立 DATA_DIR。优先选择新增氛围 E2E 与受影响的媒体切歌/系统控制、真实歌词用例；分析服务单独验证边界，不执行全量回归。截图、trace、媒体观察、源音乐哈希、SQLite 校验和复验指纹保存在私有 artifacts/e2e。手机模拟不代表真实 iOS Safari 验收。

## 实现与结果（2026-10-01）

正式播放器保留既有的双媒体元素交接、转码偏移和 Media Session 生命周期，在播放手势中接入持久 Web Audio 分析，视图切换仅改变界面。舞台资源随正式客户端准备好，点击入口无需另等界面资源；场景仅在氛围视图挂载，离开后释放渲染资源。正式歌词、收藏、队列和选曲都调用原有 API/状态，没有演示音频或演示歌词路径。

灯光分析接口使用登录保护与索引记录，校验真实源路径，以版本及文件指纹区分缓存。同源请求合并，最多两个解码任务，超时 60 秒、分析长度 45 分钟，缓存上限 256 份；结果仅写 `DATA_DIR/lighting`。解码不生成播放文件，也不改变 AAC 直传和 ALAC/FLAC 转码策略。分析失败、繁忙或旧请求晚到不会替换当前曲目的编排或阻塞播放。

以下批次位于私有 `artifacts/e2e/`，时间为 UTC：

- `2026-10-01T10-44-39-134Z-atmosphere`：实现前的需求用例在旧正式版缺少声音分析处失败。初版通过桌面流程后，手机用例误用了桌面专属播放入口；改为点击实际可见的歌曲入口后通过，产品布局未改。
- `2026-10-01T10-51-14-272Z-atmosphere`：编排接口鉴权、实际缓存、查询参数拒绝、源符号链接边界，以及切歌丢弃晚到编排两项通过。此前发现 Fastify 默认移除多余查询参数，接口增加验证前拒绝，随后同一失败用例通过。
- `2026-10-01T10-51-45-771Z-playback-media-session-lyrics`：9 项相邻回归通过，覆盖 AAC/ALAC/FLAC 实际播放、暂停跳转、自然结束与刷新重播，AAC/ALAC 逐词时间与逐行退回，系统媒体控制、双音源交接和连续切歌/退出释放。
- `2026-10-01T11-03-34-896Z-atmosphere-media-session`：最终生产构建，正常动效下桌面 AAC、393×852 ALAC 的普通页/氛围往返通过。各记录 21 个连续采样，均保留同一媒体元素、非零声音，没有新建音源连接或暂停、加载、seek、等待、停滞事件。媒体分别推进 0.5248/0.5269 秒，观察时钟推进 0.5274/0.5267 秒。面板用例首次取到了完整播放器的入场位置；补充等待入场结束后再比较。
- `2026-10-01T11-04-52-789Z-atmosphere-media-session`：复用最终构建，6 项通过：22 种灯光、歌词/队列布局和外侧关闭；分析失败、静音/恢复与 Canvas 降级；无 AudioContext 的原生播放、声音授权失败重试与错误提示清除；实际解码参考鼓点；AAC/ALAC 系统媒体操作。22 种灯光的 24 个灯源最大坐标位移为 0。357 个渲染采样中，9 个已知鼓点均在 150 ms 窗口内形成 5.08–5.21 倍亮度反差，250–380 ms 后回落到峰值的 18.3%–18.7%；暂停后画面静止。

动效验收早期沿用了全局“减少动态效果”配置，只得到静止画面；正式动效用例已显式使用正常动效，并保留减少动态效果切换。授权边界用例另补充等待真实偏好写入后刷新。以上失败产物保留，均未依赖自动重试掩盖失败。

共 17 项不同的定向 E2E 分批通过。声音授权保护的最后调整只影响恢复失败分支，已追加对应验证及 AAC/ALAC 系统操作；其余未改变的路径复用上一批结果。`tests/lighting.test.ts` 的 4 项分析服务边界通过，覆盖真实解码、只读缓存重用/损坏/源变更、源与缓存目录越界、同源合并、并发上限、关闭取消和处理中源变化；解码前复查源版本后，精确复验相关两项通过。最终类型检查、生产构建及差异检查通过，没有执行全量测试。

截图、实际音频/灯具观察、只读源哈希、SQLite 完整性和请求日志位于对应 E2E 报告；精选桌面、手机、降级及鼓点画面位于私有 `artifacts/ui/2026-10-01-production-atmosphere/`。音源为临时生成的 AAC/ALAC/FLAC/MP3 及已知节拍信号，未将测试服务指向真实曲库或用户数据库。浏览器观察不等同于扬声器到屏幕的外部延迟测量；未覆盖真实 iOS Safari、NAS 部署和蓝牙音频延迟。
