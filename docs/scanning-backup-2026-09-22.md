# 扫描与数据恢复交付记录

目标：让日常重扫更轻量，服务中断或 NAS 临时掉线时保留用户整理结果，并提供可验证的数据备份恢复流程。

## 已交付

- 默认增量扫描，以音频和伴随文件的属性、解析版本及资源有效性判断是否重解析；跳过时不重写歌曲。目录封面候选按目录属性缓存，避免同目录多首歌曲反复枚举整个目录。
- 本地歌词和目录封面的新增、修改、移除，以及失效缓存都会触发处理；成功解析与增量状态在同一事务中提交，失败下次重试。
- “重新解析全部”用于强制读取音频，启用在线补全时重试相关缓存查询；保留 AAC M4A 直传、ALAC M4A 转码识别。
- 默认保留缺失索引。只有显式清理、非空且完整无错误的扫描通过根目录及子目录身份检查后，才移除缺失歌曲。整目录不可访问也会拒绝，避免部分挂载丢失被当作歌曲删除。
- 扫描记录增加已解析、跳过及扫描选项；旧数据库通过新增列保留历史。启动持锁后将遗留 `running` 标记为 `failed`，保留已提交索引与检查进度。重新扫描会跳过已处理文件，不自动后台重启扫描。
- 页面增加扫描选项、清理确认、统计、中文断开/权限提示及失败重试。完成和失败都会触发一次曲库刷新，避免已入库新曲目一直不显示。
- 服务与维护工具共用 SQLite 独占运行锁，避免多个实例或还原过程同时写同一数据目录；配置读取保持只读，缓存目录在持锁后创建。
- 新增 `data:backup`、`data:restore` 命令：备份数据库和缓存，检查清单、SHA-256、SQLite 完整性与外键，恢复只写新/空目录，并重定位缓存路径。
- 还原保留歌曲 ID、音乐绝对路径和歌单顺序。中断标记可阻止启动半还原目录；密码、密钥及真实音乐不在备份中。

具体使用方法见 [README](../README.md#数据备份与恢复)。

## 自动化验证

`npm run typecheck`、`npm test`、`npm run build`、`git diff --check` 全部通过。测试共 **20 个文件、330 项**，本轮新增 82 项。

新增覆盖包括：旧扫描表迁移、多条中断任务恢复、相同时间戳任务更新、严格扫描选项类型、跳过与强制解析、伴随文件变化、缓存路径安全、挂载和目录丢失保护、重复提交、扫描终态刷新、跨进程锁及强杀释放、锁前无副作用启动、备份校验、WAL 快照、恢复路径重定位和禁止覆盖。

审查及实际验收修复了新锁日志误判恢复目录非空、恢复忽略当前音乐路径，以及服务在取得锁前创建缓存目录的并发问题。

## 实际进程与 CLI 验收

使用独立临时目录中的 600 首真实可解析静音 MP3，关闭在线补全：

| 场景 | 实测结果 |
| --- | --- |
| 扫描中强制终止进程 | 在已报告检查 20/600 时发送 SIGKILL；重启后显示中断失败，锁自动释放 |
| 中断后重扫 | 跳过已提交的 23 首，解析其余 577 首，0 错误 |
| 无变化重扫 | 0 首解析，600 首跳过 |
| 歌词新增、音频属性变化、新增歌曲 | 仅解析 3 首，跳过 598 首，总数 601 |
| 服务运行时执行备份 | 命令拒绝，提示先停止服务 |
| 停服后备份并恢复新目录 | 601 首歌曲、1 个收藏、歌单 2 首及顺序保留 |
| 缓存路径恢复 | 歌曲和元数据缓存中的路径改为新 DATA_DIR，音乐路径不变；新服务可返回恢复的歌词 |
| 覆盖现有 DATA_DIR | 命令拒绝，原数据保留 |
| 修改备份歌词文件后恢复 | 哈希校验失败，目标不产生可用数据库 |

独立审查也验证了源数据库仍有未 checkpoint 的 WAL 时，快照及恢复保留已提交歌单数据。

## 桌面浏览器验收

使用上述还原目录运行生产构建：

- 扫描选项、4 项统计和持久化扫描记录正常显示。
- 临时移走 1 首样本后，默认扫描跳过 600 首并保留缺失索引；收藏和歌单仍存在。
- 清理确认可取消；确认后清理 1 首，歌单从 2 首变为 1 首，对应收藏移除，其余 600 首保留。
- 强制重扫显示解析 600、跳过 0。
- 临时移走整个样本目录模拟 NAS 断开：扫描失败，中文提示确认挂载，歌单与索引保留。
- 恢复目录后点击“重新扫描”，显示解析 0、跳过 600、错误 0。
- 浏览器验收未发现未捕获的运行错误。

验收没有向原曲库或数据库写入测试内容。原有数据库的 1,054 首歌曲、收藏、2 个歌单及成员记录与验收前一致；临时服务、浏览器标签页和样本目录均已清理。

## 已知范围

增量判断使用文件属性；若外部工具刻意保留全部文件时间和大小，应使用强制重解析。首次升级需要建立增量记录。挂载路径迁移及整段失踪目录的批量清理不自动执行。

备份需要停服，恢复使用新目录；本轮不启用定时备份或自动删除旧备份。不包含正式 NAS/Docker 部署、真实手机后台/锁屏，以及长时间连续播放验收。
