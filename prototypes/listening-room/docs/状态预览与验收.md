## 体验方式

- 初次设置：进入 setup-empty，选择音乐目录后自动进入扫描；选择「继续浏览」，再从浮动进度入口或设置查看结果。扫描状态不依赖当前路由。
- 等待状态预览会停留在稳定状态，方便审阅；扫描、列表、歌词和保存场景提供「继续演示」或「完成保存」。普通操作产生的等待状态会自动完成。
- 播放准备、缓冲和转码仅通过胶囊播放器按钮的加载动画反馈，不显示上方浮层；按钮名称与悬停提示区分当前阶段，同时保留读屏状态播报。打开沉浸播放器可查看详细等待说明。
- 播放异常显示在胶囊播放器上方，使用一致的半透明材质、胶囊圆角和对应状态图标，高度约 52 px。桌面与手机均使用轻量文字按钮，只保留一个恢复操作，「下一首」沿用播放器已有入口。手机使用简短文案，按钮触控高度为 44 px，提示条与播放器间隔约 12 px。完整异常说明可在沉浸播放器中查看。重新连接、重新播放和检查目录各有对应操作。
- 沉浸播放器的空待播清单采用居中内容组，队列图标、标题、两行说明与「回到音乐库」胶囊按钮沿同一轴线排列。手机适配内容区域高度，矮屏隐藏装饰图标并缩小间距，保留 44 px 按钮触控高度。
- 私人歌单集合为空时，空态填满标题与播放器之间的可用区域，不显示上下分隔线或独立背景。正文的新建操作集中在空态中，创建首张歌单后恢复页头的新建按钮；状态预览与真实空歌单页复用同一布局。
- 歌单封面按歌曲顺序提取不同专辑：1 张完整显示，2 张左右拼接，3 张左侧一张、右侧上下两张，4 张及以上选前 4 张组成四宫格；空歌单保留歌单图标。不会重复同一专辑来补格，封面缺失时保留该专辑的占位。列表、详情、侧栏和添加歌单弹窗使用同一组件；对照入口为 `#/preview/playlist-covers`。
- 收藏为空时，提示内容在「收藏的歌曲」与播放器之间居中，使用两行说明和 44 px 操作按钮，不显示独立背景或分隔线。手机缩小空收藏封面并收起不可用的播放按钮，给引导操作留出空间；收藏第一首歌曲后恢复原有封面和列表布局。
- 单张歌单没有歌曲时，复用收藏空态的自适应居中布局、两行说明与手机紧凑封面。添加入口集中在空态中，加入第一首歌曲后恢复列表标题旁的添加按钮；保留歌单的重命名和删除入口。矮屏收起重复图标与封面旁的零计数，操作按钮并排显示并保留 44 px 触控高度。
- 排序时按住右侧手柄拖动草稿，可一次跨越多首歌曲，边缘自动滚动。键盘支持空格/回车抓取与放下、方向键移动、Home/End 置顶置底、Esc 撤销本次移动；保存前原歌单顺序保持不变。点击取消会放弃整个草稿。
- 歌单保存失败示例保留「夜色与旋律」草稿，点击「重试保存」后应用。收藏失败示例同样在成功后才变更收藏。
- 登录使用演示账号：admin 为管理员、listener 为普通账号、newcomer 首次登录需改密、quiet 已停用。有效账号输入任意非空密码可继续；`wrong` 触发错误。会话过期示例成功后回到「深夜的耳机」。没有连接目录时，管理员进入首次设置；普通账号提示联系管理员。
- 账号页面与本轮角色流程详见 [账号页面与角色说明](账号页面与角色说明.md)。

实际交互验证：

- 首次设置中的侧栏为 0 首歌曲、0 张专辑、0 收藏、无预置歌单；播放器显示未开始播放。

- 歌单重命名成功、拖拽调整顺序后保存、删除确认后返回歌单集合。
- 歌单保存失败后重试，草稿成功应用。
- 会话过期后重新登录回到原歌单；退出显示已退出状态。
- 搜索「游戏原声」完整显示 10 张专辑；艺人分区可见，局部专辑失败可重试恢复。
- 播放断线在胶囊和沉浸播放器中一致，重新连接恢复播放；歌词重试后显示演示歌词。
- 桌面 1200×800、手机 393×852、小屏 393×667，以及暗色主题抽查。修复了小屏播放异常操作超出视口、歌词场景切换未刷新和封面占位比例问题。

构建与测试：根项目类型检查、生产构建、原型类型检查与构建均通过；`npm test` 26 个测试文件、399 项测试通过，其中新增扫描进度/中断、歌单排序草稿与元数据缺省测试；`git diff --check` 通过。

边界：这是前端交互原型，认证、扫描、播放和持久化采用内存模拟，刷新重置。未调用真实认证或扫描 API，未读写音乐文件。登录 Canvas 动画、玻璃效果、已定稿的音乐库视觉和手机胶囊外形沿用原设计。本轮未执行 Git 提交。
