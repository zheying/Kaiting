# 歌单拖拽排序验收

预览：<http://127.0.0.1:4173/#/preview/playlist-order>。

## 实现

- 歌曲右侧使用 44px 拖动手柄，一次可跨越任意多首；按目标位置插入，其他歌曲的相对顺序不变。
- 拖动时显示浮起行、落点和让位动画；列表边缘自动滚动，并限制在歌曲列表范围。
- 仅手柄禁用触摸滚动，列表其他区域仍可正常滑动；保存/取消工具栏保持可见。
- 空格/回车抓取或放下，方向键调整，Home/End 置顶/置底，PageUp/PageDown 跨五首，Esc 取消本次移动。
- 操作在草稿中完成，保存后应用，取消则恢复歌单；未引入依赖。
