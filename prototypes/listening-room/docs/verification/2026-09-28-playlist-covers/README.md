# 歌单封面数量适配验证

2026-09-28，原型入口：`#/preview/playlist-covers`。

封面使用歌曲顺序中的不同专辑，最多展示四张。1 张完整显示，2 张左右拼接，3 张左侧一张、右侧上下两张，4 张及以上使用四宫格。空歌单保留歌单图标。

## 浏览器验证

- 桌面 1108 × 879：对照页覆盖 0、1、2、3、4、6 张专辑。每个非空案例为每张专辑包含两首歌曲，最终封面分别只出现 1、2、3、4、4 张图片；未通过重复图片补格。
- 桌面示例封面均为 200 × 200px。2 张各占 100 × 200px；3 张为 100 × 200px 加两张 100 × 100px；4 张各占 100 × 100px。
- 对照页主内容无额外纵向滚动。
- 实际歌单页三个歌单分别展示 4、4、3 张封面。“深夜的耳机”详情页 210px 封面与侧栏 28px 缩略图均为三图布局。
- 手机 393 × 852：所有示例封面均为 162 × 162px，保持数量与布局规则；页面无横向溢出。对照页六个案例通过正常纵向滚动查看。
- 浏览器控制台未发现错误。
