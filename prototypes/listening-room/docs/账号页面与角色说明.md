# 音泊账号页面与角色说明

更新日期：2026-09-27。

## 页面入口

| 页面 | 直接预览 | 正常入口 |
| --- | --- | --- |
| 管理员个人账号 | `#/preview/account` | 登录后侧栏「我的账号」或设置中的「账号设置」 |
| 普通账号 | `#/preview/account-member` | 使用 `listener` 登录后打开「我的账号」 |
| 登录与安全 | `#/preview/account-security` | 账号页「登录与安全」标签 |
| 用户管理 | `#/preview/accounts-manage` | 管理员账号页「用户管理」标签 |

普通路由为 `#/account`、`#/account/security`、`#/admin/users`。未登录直接访问会显示登录引导；普通账号直接访问管理路由会显示权限不足。所有状态均收录在 `#/preview` 的「账号与音乐室成员」组，账号组共 12 项，总览现为 59 项。

## 角色范围

| 能力 | 普通账号 | 管理员 |
| --- | --- | --- |
| 浏览、搜索与播放共享曲库 | 可以 | 可以 |
| 自己的收藏、私人歌单、资料和密码 | 可以 | 可以 |
| 管理自己的登录设备 | 可以 | 可以 |
| 查看其他账号的私人收藏与歌单 | 不提供 | 不提供 |
| 连接目录、发起扫描、查看扫描结果 | 不提供 | 可以 |
| 创建账号、分配角色、停用和启用账号、重置密码 | 不提供 | 可以 |

自己的账号不能自行停用或更改角色，音乐室至少保留一位可用管理员。授予管理员权限需在表单中明确确认。停用、退出设备、重置密码及退出当前账号均有说明和确认步骤。停用不会移除该账号的收藏与歌单。

个人资料支持昵称、介绍和头像颜色，用户名保持固定。用户列表支持搜索、按状态和角色筛选、载入中、载入失败重试和搜索无结果。个人资料保存失败保留草稿，可重试或取消。

账号筛选使用自定义下拉面板：圆角与主题配色跟随音乐室，选项带图标及选中标记，当前筛选在按钮中突出显示。支持方向键、Home / End、回车或空格确认、Esc 取消和 Tab 移出；点击外部会收起。触控选项至少 44 px 高，面板根据可用空间向上或向下展开，并避开搜索栏与播放器；空间不足时内部滚动。桌面、手机短屏、暗色主题及搜索联动已验证，截图见 `verification/2026-09-27-account-filter/`。

## 登录与账号操作

- 示例账号：`admin` 为管理员，`listener` 为普通账号，`newcomer` 需要首次改密，`quiet` 为停用账号。
- 有效且可用的演示账号输入任意非空密码可继续，`wrong` 会演示密码错误。凭据不写入存储、不发送请求；新密码表单校验长度和确认值，但原型不会验证后续登录是否匹配此前设置的密码。
- 管理员创建账号时只填写用户名、昵称与角色。点击「创建账号」且校验通过后，自动生成 12–22 位随机临时密码，包含大小写字母、数字及符号，并避开易混淆字符；使用 Web Crypto 安全随机源，生成失败时保留表单且不创建账号。
- 创建成功弹窗显示用户名、角色与临时密码，支持密码显隐和「复制登录信息」。临时密码只保留在该弹窗的内存状态，关闭后清除；复制失败时可显示密码并手动复制。新账号首次登录必须设置自己的密码。管理员重置密码后同样进入首次改密流程，已有会话在演示状态中失效。
- 修改自己的密码后退出全部设备并回到登录，登录页提示密码已更新。
- 切换账号时保存各自的内存收藏与歌单，停止播放、清空当前待播内容，避免沿用上一个账号的私人内容。重新登录可取回该账号在本次演示中的修改。
- 普通账号的设置只提供个人显示偏好和共享曲库说明；共享曲库为空时提示联系管理员。

## 输入提示与校验

- 必填字段标记星号，个人介绍标记选填。用户名提前说明格式、长度、不区分大小写及创建后不可修改；昵称、介绍显示字符计数。
- 创建账号、编辑资料、管理账号、修改和重置密码、登录、首次改密共用逐字段校验。初次输入展示规则，离开字段或提交时显示错误；修正后即时更新，不在中文输入法组字过程中报错。
- 用户名校验非法字符、开头、2–24 字符长度及重复（含停用账号）。昵称最多 24 个字符，介绍最多 80 个字符。Unicode 补充字符按一个字符计数，不静默截断内容。
- 自己修改密码、首次改密和管理员手动重置的临时密码要求 8–64 个字符且不能全部为空格；确认密码随上方密码修改重新校验。新密码不能复用当前或临时密码。保留密码中的空格及大小写，提供显隐切换和大写锁定提醒。创建账号不再显示或校验密码输入框；已有登录密码不套用新密码长度规则。
- 提交时显示全部字段问题，并聚焦、滚动至第一处错误。提示通过 `aria-describedby` 关联字段，错误标记 `aria-invalid`，文字配合图标区分状态。输入框聚焦使用单层边框，无外层红色光圈。
- 账号权限确认错误显示在对应勾选项下；当前密码错误显示在当前密码下。登录网络中断、账号停用与凭据错误分开呈现，网络和停用状态不会将密码误标为格式错误。
- 手机长表单及登录卡片支持内部滚动，保持圆角；明暗两套主题均有对应提示颜色。

验证截图见 `verification/2026-09-27-input-feedback/`。已在界面验证创建表单的错误、修正与成功保存，以及资料长度、当前密码错误、管理员确认、登录错误和首次改密的校验。首次改密的最终保存测试被自动审批拦截，未执行；字段校验和布局已检查。本次新增 7 项校验测试，现共 413 项测试通过。
