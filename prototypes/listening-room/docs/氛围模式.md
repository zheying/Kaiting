# 氛围模式原型

氛围模式提供主动观看音乐的舞台体验，从原播放页右上角进入。实现仅位于独立原型；正式客户端、服务端、账号与数据库不在本次修改范围内。

## 预期体验与失败方式

固定灯位修正的预期：24 盏灯具有统一、不随灯光模式或音乐变化的舞台安装坐标。模式切换只过渡照射方向、角度、强度和色彩；手机使用投影适配，不挪动舞台中的灯具。需要防止单个模式重排灯具、过渡插值引起漂移、窄屏重排以及修复后光束不再扫动。针对实际 WebGL 提交逐帧观察所有灯源坐标，覆盖全部 22 种模式、自动编排与桌面/手机；复用 Canvas 降级的相关验证并保留截图，不重跑无关音频或接口测试。

| 场景 | 预期行为与需要避免的失败 |
| --- | --- |
| 真实录音 | 按原始专辑、曲名、时长和碟/轨号唯一匹配；匹配不明确时明确失败，不拿别的录音或演示音源替代 |
| 音乐调度 | 每首歌有自己的灯光时间轴；根据动态、频段、起音密度和渐强换构图，避免按固定时间随机轮播 |
| 灯光丰富度 | 追光、光幕、侧光、扇面、追逐、穹顶、双翼、光浪、环绕、星点、光廊与齐射有明确的构图区别 |
| 拖动与切歌 | 音频时钟决定进度和灯光；拖动后定位对应段落；旧曲准备晚到不能覆盖新曲 |
| 播放控制 | 暂停不继续运动；静音保留音乐分析；真实曲终支持单曲循环与队列切换；进入/退出氛围模式、收起播放页均继续播放 |
| 模式切换 | 共用音频元素、音频图、队列与播放设置；往返时无暂停、seek、重新准备或加载事件；暂停状态同样保留 |
| 失败恢复 | 文件不可读、ALAC 解码失败、准备/请求失败时显示可重试反馈；分析失败可明确降为实时调度 |
| 只读边界 | 音乐源不写入；缓存在独立目录；越界、符号链接逃逸、非法 Range、重复匹配均被拒绝；准备并发有上限 |
| 手机与面板 | 选曲、灯光选择与播放控制可操作；面板可滚动、Esc 分层关闭，窄屏无横向溢出 |
| 画面生命周期 | 减少动态效果时静止；后台停止绘制；WebGL 不可用或上下文丢失时降级，恢复后继续观看 |

新增模式的失败方式还包括构图同质化、手机面板无法选到新增项目、降级后黑屏或减少动态效果仍继续运动，以及旧缓存阻止新模式参与编排。沿用真实录音、固定灯位和渲染边界用例扩大到 22 种构图，增加独立缓存升级验证，保留手动选择与自动调度的截图。

共用播放会话的预期：普通播放开始后，往返氛围模式和收起播放页应始终保留同一个媒体元素与音频图，媒体时间连续、真实波形有输出，不能出现暂停、重载、seek 或重复准备请求。队列内容、音量、随机与循环设置一致；暂停时切换不自动开播。相邻风险包括切歌旧请求晚到、准备/媒体请求失败的恢复、曲终循环与自动切歌，以及开发环境重复初始化音频图。先在旧实现上运行连续播放用例确认失败，再用上述边界复验。

氛围面板的预期：歌词、队列的开关和互切不能压缩舞台、改变画布尺寸或挪动播放控件，也不能突然给整幅灯光罩上暗层。文字轻量叠加，进出均渐隐；快速互切不闪烁，不残留可点击或可聚焦的旧内容。关闭恢复入口焦点，减少动态效果跳过过渡。相邻验证覆盖歌词跳转、闲置时保留歌词、手机队列编辑、窄屏不遮挡控件，以及真实音乐播放连续性。先在旧实现复现舞台与控件位移，再修改布局和面板显示生命周期。

验证由以上需求与失败方式决定。真实音乐使用用户明确授权目录，只做读取；文件故障只注入临时曲库，缓存和报告均在独立数据目录。复用直接受影响的音源/渲染 E2E，不执行全量测试，也不为视觉实现补镜像单元测试。

## 当前实现

### 真实音源

原型启动时读取 `PROTOTYPE_MUSIC_ROOT`；配置方式见 [README](../README.md#本地真实音乐)。目录递归扫描跳过隐藏项与符号链接，路径访问复用正式服务的 `safeRealPath`，没有修改正式路径工具。当前快照的 1,054 首曲目全部唯一匹配，曲目接口不返回本地路径。

兼容格式直接播放；ALAC 等格式复用正式格式判定，在本机用 FFmpeg 生成 AAC 播放缓存。原始录音与标签不变，也不上传音频。每次首次准备记录源文件前后 SHA-256。缓存位于原型独立数据目录，最多两项并发准备，同曲请求复用任务；单曲上限 45 分钟。按 512 MiB / 48 个音频与分析文件淘汰旧缓存，单次准备可能临时超过容量阈值。

播放进度、曲终事件和灯光同步使用真实媒体时钟。切歌取消旧前端请求，并通过当前曲目身份阻止旧音源/分析覆盖新曲；后台已经开始的准备有超时和并发上限。选择真实曲目沿用现有队列规则，不另建播放队列。普通播放页、氛围模式和胶囊播放器共用 App 中常驻的音频元素和 Web Audio 图；画面切换不调用停止、重新加载、跳转或重新授权音频。模式与路由不参与音源生命周期，切歌、清空当前曲目或显式重试才重载。退出氛围模式恢复原面板，音乐和真实进度持续推进；暂停、音量、随机与循环设置同步保留。歌词仍是明确标注的原创示例，不声称是真实歌词。

未配置曲库时才启用 38.4 秒原创合成音源 `public/audio/atmosphere-demo.wav`，界面标注“原创演示音源 · 非本曲音频”。三个播放界面均明确标注演示音源，演示进度仍按快照时长模拟。配置曲库后的匹配/读取失败不会回退成演示音乐。

### 灯光时间轴与实时响应

本机先以 100 ms 窗口读取整首录音的 RMS、低频比例、高频比例与起音；比较本曲动态范围、局部能量、起音密度、前后强弱变化，形成可重复的灯光时间轴。通常保留一个构图 7–9 秒，高能释放可较快切换，尾音允许收束。安静录音会更多使用追光、光幕与穹顶；明亮旋律、密集节奏和低频各有不同构图倾向。

默认「跟随音乐」，拖动后直接定位时间轴；顶端说明当前构图与“轻奏留白 / 渐强展开 / 高能释放”等声音依据。实时 Web Audio 继续驱动亮度、展开程度、扫光与重拍强调。手动选择只固定构图，声音仍驱动明暗和运动。静音在分析器之后调整输出增益，不把静音误判为音乐留白。分析失败时显示提示，并用实时能量、起音与频段调度。

重拍使用独立的快速响应：读取未被 byte 频谱上限裁切的线性幅度，比较低频、中频、高频的正向频谱变化与近期基线。低频起音强调后排，清脆起音带动交替顶灯和侧光；已有亮起的光束瞬时增强、略微收窄并偏向暖白，随后快速回落。慢速扫光和铺陈亮度继续独立运行，拍间保留暗部。轻柔强度以及追光、星点、双束、余晖构图降低重拍强调幅度，持续低音不反复触发起音。

起音检测使用音频时钟，灯光回落使用实际帧间隔，均不依赖舞台运动的快慢。暂停、跳转、换源或长时间未读取后重建频谱历史，并清除旧的强调；初始化首帧不参与起音基线，避免把后续第一拍压掉。短暂预热与触发间隔用于抑制寻址突变和同一次敲击的重复响应。这里识别的是声音瞬态，仍不等同于分离底鼓、军鼓等乐器，也不会为没有敲击的段落补出固定节拍。

编排版本为 5。新增柔和与强烈构图按声音条件进入调度；已识别为轻柔的录音持续使用舒展、细束或铺色，避免相对能量高点触发强烈齐射。磁盘缓存版本不匹配时重新分析，已有转码音频继续复用；前端重载后获取新时间轴。版本 5 将花影与百叶用于轻奏、旋律段，扇屏用于渐强，接力用于密集节奏。

这是基于声音特征的原型规则，不是语义上的主歌/副歌识别，也不声称精确识别 BPM、乐句或乐器。自动编排使用有条件的保持与平滑过渡，不是固定间隔随机换模式；当前未做灯光师人工编程或用户自定义时间轴。

24 个固定安装位置属于舞台：8 盏后排灯、8 盏顶灯、4 盏侧光、4 盏铺光。所有模式共享这些坐标，包括追光、星点、环形和光廊；切换只插值照射方向、角度、强度与色彩比例，不对灯源位置做插值。三维散射保留亮芯、雾、地面接光与倒影。花影与百叶使用沿灯轴投影的图案片，图案同样作用于雾与地面；切换时渐变图案强度，安装坐标不变。默认暖白和琥珀，另有暗红与深蓝；轻柔/鲜明控制运动与强调幅度。窄屏通过横向投影适配，舞台里的灯位不变；WebGL 与 Canvas 使用同一组安装坐标。

体积光围绕各灯轴邻近区域采样，宽幅铺光用解析雾层。带图案的灯束提高雾采样密度以减少离散切片；普通光束保留原采样数量。Canvas 降级保留地面的花瓣与条纹图形。桌面画布上限 55 万像素，窄屏 40 万，DPR 上限 1.4。Canvas 降级复用相同灯位；暂停后短暂收敛并停止，减少动态效果时保持静止，后台不持续绘制。全屏、歌词/队列、闲置隐藏和音量保留原有功能；新增可搜索的真实选曲面板和 22 种灯光选择面板。

### 与正式播放页保持一致

普通播放页与氛围模式均隐藏转换说明卡片；准备期间保留播放按钮的加载状态，连接或播放失败仍提供重试。三个播放器（胶囊、普通播放页、氛围模式）复用正式版 `useSeekInput`，拖动或按键时只预览位置，手势结束后提交；切歌取消尚未提交的旧进度，音源准备期间禁用进度调整。正式组件源码保持不变。

真实曲库的音质标识只在曲目明确为无损时显示“无损”；未配置曲库时该位置明确标注原创演示音源。原型快照目前均为 ALAC。无歌词提示与重新查找入口、歌词前景颜色同步正式版；示例歌词、模拟查找与渐进动画仍属于原型演示，不接入正式歌词服务。

### 氛围歌词与待播清单

歌词进度直接复用正式版 `SyncedLyrics` 与基础样式，普通播放页和氛围模式使用相同组件。真实曲目的 `readPosition` 从当前音频元素读取时间，只有曲目身份一致且媒体元数据就绪时才使用媒体值，避免切歌准备阶段读到上一首的位置；未配置曲库的合成循环使用原型模拟歌曲时间轴。原型保留原创示例文字、无歌词和模拟重新查找入口，没有连接正式歌词服务。

示例数据只提供行时间，因此按句高亮，删除了将整句时长均分到每个字的模拟进度与 0.85 秒 CSS 补间。复用的正式组件只在数据包含逐词时间时按实际起止时间推进高亮，播放期间局部采样媒体时钟；暂停、回拖与切歌直接重新定位。氛围配色沿用当前主题，着色边界与正式规则一致。

舞台画布始终铺满屏幕，歌词和队列都作为独立前景叠加，不调整舞台、导航和底部控制的位置。歌词居中显示当前句和相邻句，用文字层级及上下渐隐融入灯光；待播清单去掉不透明卡片与边框，以局部柔和暗影保证可读性，仍使用普通播放页的同一队列及操作。

面板入场 380 ms、离场 260 ms，只改变自身透明度和 8 px 的垂直偏移。关闭时保留视觉内容直到离场结束，同时立即设为 `inert` 并从辅助功能树隐藏；再次打开从当前帧继续。歌词与队列互切使用独立生命周期交叉淡化，关闭或 Esc 将焦点交回对应按钮。减少动态效果偏好不播放过渡。

歌词开启时仍可闲置隐藏控制，保留随音乐推进的文字；队列开启时保持操作入口可用。手机使用更紧凑的显示区域，保留滚动、更多操作、44 px 高的排序/移除按钮和底部播放控制；320×568 的小屏也不压缩舞台或遮挡控制。

灯光编排、真实选曲和画面设置支持点击或轻触窗口外侧关闭。内部点击、搜索和滚动不触发外侧关闭；各入口仍能一次开关或切换窗口。外侧关闭只收起临时浮窗，保留歌词/队列、灯光和播放状态；Esc 继续按层关闭。关闭含焦点的浮窗时，将焦点交回舞台，再由实际点击的控件接收正常焦点。
