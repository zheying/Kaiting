# Music Library · 私人音乐空间

一套独立的 React / Vite 交互原型，以私人唱片收藏为视觉方向。入口和样式位于本目录，不替换现有客户端或服务端。

## 启动

在仓库根目录执行（复用根目录已经安装的依赖）：

```bash
npm install
npm run prototype
```

打开 <http://127.0.0.1:4173/>。开发服务器仅监听本机，默认使用 4173 端口。

构建与预览：

```bash
npm run prototype:build
npm run prototype:preview
```

构建输出在本目录的 `dist/`，不影响主项目的 `dist/client/`。

## 可以体验什么

- 首页：以真实专辑封面呈现今日精选，可直接播放或查看专辑；今日精选与继续聆听组成以细分隔线承载的开放式焦点区，主专辑使用大封面，继续聆听收束为轻量播放栏，避免重复的白色卡片边界。最近加入与私人歌单使用封面卡片和下置文字，歌单封面快捷播放入口在悬停或键盘聚焦时出现。歌单与歌单页复用同一组件，可直接播放。手机端专辑横向浏览，歌单按两列展示。
- 曲库：专辑页从标题区直接进入封面网格，不再显示重复结果标签或独立筛选、排序和视图切换工具栏；网格中仅封面保留圆角与浅阴影，名称、艺人和年份放在封面下方的页面背景上。歌曲页使用白色列表，格式筛选采用轻量文字标签和红色下划线选中态，空结果可一键恢复全部歌曲。专辑、艺人作品、收藏和歌单详情统一封面、元数据及播放区，专辑支持分碟浏览；收藏与歌单详情的拼图封面单独作为卡片，标题、描述与播放操作位于页面背景。歌单卡片可直接播放。手机长歌名最多显示两行，更多操作为 44px 触控区域。
- 公共框架：艺人页已确认的中性灰白、磨砂侧栏、浅阴影、搜索框和红色选中图标已推广到所有页面。顶栏只保留全局搜索，手机端增加侧栏入口；详情页继续使用内容区的返回按钮。侧栏歌单显示封面缩略图，导航可独立滚动，曲库数量和设置固定在底部；窄桌面保留歌单与设置图标。专辑网格、首页最近加入、艺人作品、搜索结果、艺人列表和歌单展示共用封面圆角与浅阴影，文字放在页面背景上；艺人卡片整体可点击进入作品页。
- 搜索：歌曲、艺人、原始专辑名与中文展示名称，包含空结果状态。
- 收藏与歌单：收藏切换、新建歌单、名称校验、加入歌单、防重复添加、移除歌曲。
- 播放交互：播放/暂停、上一首/下一首、进度调整、随机与循环、音量状态。
- 待播清单：追加歌曲、下一首播放、上下调整顺序、移除、清空其他歌曲。
- 沉浸播放：参考 Apple Music 的融合布局，采用浅色封面氛围、三键播放控制与按需展开的歌词/队列。宽屏收起状态为左侧大封面、右侧曲名与播放控制；展开歌词或队列后，播放信息聚合到左侧，内容在右侧展示。窄屏展开时将封面收为顶部小图，底部控制持续可用。音量独立成行，短窗口合并到歌词/队列按钮之间。歌词、待播清单、随机与循环通过红色图标和描边加粗表示选中，悬停也不增加底色。随机和循环入口位于队列标题旁。播放时背景缓慢流动，切换面板时封面与控制平滑移动。
- 歌词演示：点击歌词按钮展示原创示例歌词。当前句逐字渐进着色，在可视区域约 40% 高度处自动跟随，远处句子柔化并在上下边缘渐隐。点击任一句跳转到对应时间；手动滚动或键盘浏览暂停跟随并恢复文字清晰度，可点击“回到当前歌词”恢复。右上角“无歌词”与空态中的“查看演示歌词”可切换两种效果。
- 底部播放器沿用原客户端胶囊：桌面居中磨砂胶囊、悬停进度和展开音量；手机为 52px 高度、32px 方形封面和黑色按钮。手机端通过左上角打开侧边栏切换页面，移除重复的底部导航；胶囊距底部安全区 12px，内容和提示同步预留间距。
- 桌面最小宽度为 480 CSS px，窄窗口使用原版紧凑胶囊；设备判断复用现有 `useMobileLayout()`。
- 键盘：⌘/Ctrl K 搜索、空格切换播放，滑条支持方向键。播放页的 Esc 优先收起歌词或队列，再次按下返回音乐库；其他弹窗可用 Esc 关闭。

建议体验路径：**首页 → 专辑 → 播放 → 打开沉浸播放器 → 待播清单 → 收起 → 歌曲更多菜单 → 添加到新歌单**。

## 原型边界

这是视觉和交互演示，**没有音频输出**。进度、音量和播放状态在前端模拟；没有连接音频流、账号、扫描或其他服务端接口。收藏、歌单与设置只保存在当前页面的内存中，刷新后重置。

歌词使用本原型原创的 16 行示例文字，时间点按当前曲目时长映射，用来体验排版、跳转和滚动；界面标注“原创演示 · 非本曲歌词”。逐字推进按句子时长均分，仅演示视觉效果；这些不是曲库歌曲的实际歌词，也没有接入音频、逐字时间轴或歌词服务。

`src/library.json` 使用本地数据库的只读元数据快照：11 张专辑、1,054 首歌曲。不包含音频路径、凭据、数据库或音频文件。专辑中文名和示例歌单为原型展示文案，原始专辑名保留在详情页。歌曲格式以快照为准。

封面复制自已有的 `DATA_DIR/artwork` 缓存；复制前对记录推导出的源路径执行了 `safeRealPath`。当前首页主视觉直接复用专辑封面；早期照片素材保留在原型资源中。原型未修改音乐文件或真实收藏、歌单数据。封面权利属于相应作品的权利人，当前用于本地个人设计预览。

使用系统字体和项目已有的 Lucide 图标，未新增前端依赖。

## 文件

- `src/App.tsx`：页面、导航、交互状态和弹窗。
- `src/styles.css`：公共视觉变量、基础排版、桌面与手机样式。
- `src/shell.css`：共用侧栏、搜索栏、按钮、卡片、列表与弹窗的中性视觉样式。
- `src/home.css`：首页推荐、继续聆听、收藏与曲库概览的响应式布局。
- `src/catalog.css`：专辑、歌曲、收藏、歌单、搜索以及各类详情页的布局与响应式规则。
- `src/artists.css`：艺人卡片的专用排版，复用公共视觉变量。
- `src/NowPlaying.tsx`、`src/now-playing.css`：浅色沉浸播放页，包含播放控制、音量、歌词、队列及响应式布局。
- `src/DemoLyrics.tsx`、`src/demo-lyrics.css`：带时间点的原创歌词演示、逐字着色、滚动跟随、远处柔化和手动浏览。
- `src/CapsulePlayer.tsx`、`src/capsule-player.css`：原版胶囊的独立原型适配，复用原客户端 `PlayerMarquee`；`src/PlayerIcons.tsx` 沿用原播放器图标。
- `src/library.json`：展示用元数据快照。
- `public/artwork/`：独立封面资源。
- `design-qa.md`：验收记录。
- `docs/screenshots/`：浏览器截图。

运行 `npm run prototype:build` 检查原型类型和生产构建；主项目仍使用原有的 `npm run typecheck`、`npm run build` 和 `npm test`。
