# 开听 · 私人音乐空间

一套独立的 React / Vite 交互原型，以私人唱片收藏为视觉方向。入口和样式位于本目录，不替换现有客户端或服务端。

## 启动

在仓库根目录执行（复用根目录已经安装的依赖）：

```bash
npm install
npm run prototype
```

打开 <http://127.0.0.1:4173/>。开发服务器仅监听本机，默认使用 4173 端口。

构建与预览：

```bash
npm run prototype:build
npm run prototype:preview
```

构建输出在本目录的 `dist/`，不影响主项目的 `dist/client/`。

## 可以体验什么

- 首页：以真实专辑封面呈现今日精选，可直接播放或查看专辑；今日精选与继续聆听组成以细分隔线承载的开放式焦点区，主专辑使用大封面，继续聆听收束为轻量播放栏，避免重复的白色卡片边界。最近加入与私人歌单使用封面卡片和下置文字，专辑与歌单封面的快捷播放入口在悬停或键盘聚焦时出现，移动端默认保持隐藏。歌单与歌单页复用同一组件，可直接播放。手机端专辑横向浏览，歌单按两列展示。
- 曲库：专辑页从标题区直接进入封面网格，不再显示重复结果标签或独立筛选、排序和视图切换工具栏；网格中仅封面保留圆角与浅阴影，名称、艺人和年份放在封面下方的页面背景上。歌曲页使用白色列表，格式筛选采用轻量文字标签和红色下划线选中态，空结果可一键恢复全部歌曲。专辑、艺人作品、收藏和歌单详情统一封面、元数据及播放区，专辑支持分碟浏览；收藏与歌单详情的拼图封面单独作为卡片，标题、描述与播放操作位于页面背景。歌单卡片可直接播放。手机长歌名最多显示两行，更多操作为 44px 触控区域。
- 公共框架：艺人页已确认的中性灰白、磨砂侧栏、浅阴影、搜索框和红色选中图标已推广到所有页面。顶栏只保留全局搜索，手机端增加侧栏入口；详情页继续使用内容区的返回按钮。侧栏歌单显示封面缩略图，导航可独立滚动，曲库数量和设置固定在底部；窄桌面保留歌单与设置图标。专辑网格、首页最近加入、艺人作品、搜索结果、艺人列表和歌单展示共用封面圆角与浅阴影，文字放在页面背景上；艺人卡片整体可点击进入作品页。
- 搜索：歌曲、艺人、原始专辑名与中文展示名称，输入时显示候选，提交后进入完整结果，并包含无匹配状态。
- 登录入口：`#/login` 是整屏沉浸式登录页，表单漂浮在 Canvas 2D 绘制的连续声波上。多组细线共享一个时间轴，每帧先在缓冲画布完成，再一次性呈现；画布不参与 CSS 缩放或虚线动画。半透明面板保留独立的轻微浮动与边缘呼吸，页面不依赖背景图。后台标签页暂停绘制，减少动态效果偏好使用静止画面。页面采用用户名与密码登录，提供密码显隐、空值/密码错误、连接失败、账号停用、会话过期和登录成功反馈；新账号或重置密码后先设置新密码，成功后返回原访问位置，管理员尚未连接目录时进入首次设置。“查看演示”可直接进入音乐室；已登录后侧栏的「我的账号」进入账号页面。
- 账号与成员：`#/account` 管理昵称、介绍和头像颜色，`#/account/security` 管理密码与登录设备，管理员可在 `#/admin/users` 搜索/筛选成员、创建账号、调整角色、重置密码、停用和重新启用账号。普通账号没有管理入口，直接访问管理地址会显示无权限状态；共享音乐目录由管理员维护，各账号的收藏与歌单在本次演示会话中相互独立。
- 缺省与异常：空收藏、空歌单、空歌单集合、无格式歌曲、空专辑碟片和无艺人作品均有下一步操作；`#/loading` 可预览载入状态，失效内容与未知页面使用独立 404 状态，`#/error` 可直接预览曲库读取失败页。曲库读取异常进一步拆成“初次设置”“目录不可访问”“扫描部分失败”和“扫描完成”，分别提供选目录、自动扫描、重试、换目录、查看失败文件、保留可读取内容和进入曲库的处理路径。
- 状态总览：`#/preview` 集中展示 60 个正常、缺省与异常场景，也可从设置的「设计状态预览」进入。每次进入场景重置内存演示数据，首次设置同时呈现零计数侧栏、空歌单与空播放器。选目录后自动扫描，离开页面仍继续，可从设置重新查看结果。详细入口与操作见 [状态预览与验收](docs/状态预览与验收.md)。
- 收藏与歌单：收藏切换、新建歌单、名称校验、加入歌单、防重复添加、移除歌曲；新增重命名、删除确认、拖拽调整顺序与保存/取消。排序支持桌面与手机拖动、边缘自动滚动、落点与让位动画，以及键盘空格抓取、方向键调整、Home/End 置顶置底、Esc 撤销单次移动；保存失败时保留修改并支持重试。
- 播放交互：普通播放页、氛围模式和胶囊播放器共用一个持续存在的音源与播放队列。进入/退出氛围模式或收起播放页只切换画面，保留当前曲目、真实进度、音量、随机与循环状态；暂停时切换也保持暂停。支持播放/暂停、上一首/下一首和进度调整。进度滑条复用正式版手势逻辑，拖动或按键期间预览位置，松开后提交，切歌取消旧进度；胶囊、普通播放页和氛围模式保持一致。转换期间由播放按钮显示准备状态，不弹出转换说明卡片；断线、缺失文件、解码失败和自动播放受阻保留恢复操作。歌词也有载入与失败重试状态。
- 待播清单：追加歌曲、下一首播放、上下调整顺序、移除、清空其他歌曲。
- 沉浸播放：参考 Apple Music 的融合布局，采用浅色封面氛围、三键播放控制与按需展开的歌词/队列。宽屏收起状态为左侧大封面、右侧曲名与播放控制；展开歌词或队列后，播放信息聚合到左侧，内容在右侧展示。窄屏展开时将封面收为顶部小图，底部控制持续可用。音量独立成行，短窗口合并到歌词/队列按钮之间。歌词、待播清单、随机与循环通过红色图标和描边加粗表示选中，悬停也不增加底色。随机和循环入口位于队列标题旁。播放时背景缓慢流动，切换面板时封面与控制平滑移动。
- 氛围模式：播放页右上角进入音乐舞台。提供追光、光幕、侧光、逆光、灯阵、穹顶、双翼、光浪、环绕、星点、光廊、齐射、双束对望、斜落光雨、余晖漫场、低空光海、交错织光、探照巡游、花影流转、百叶光窗、扇屏开合、节拍接力，共 22 种灯光；默认「跟随音乐」，按本曲动态、频段、起音密度和渐强安排灯光时间轴，实时声音继续驱动亮度和运动。重拍另行驱动后排、交替顶灯与侧光，快速提亮、收束并回落，拍间保留明暗反差。24 个灯位保留薄雾、纵深与地面反光，默认暖白与琥珀，另有暗红、深蓝和轻柔/鲜明强度。支持真实曲目搜索、手动灯光、播放控制、全屏、闲置隐藏、减少动态效果与 Canvas 降级。
- 歌词演示：点击歌词按钮展示原创示例歌词，直接复用正式版的歌词组件与基础样式。示例只有行时间，整句高亮，不模拟逐字进度；真实曲目直接读取媒体时钟，暂停、跳转和切歌随之定位。当前句在可视区域约 40% 高度处自动跟随，远处句子柔化并在上下边缘渐隐。点击任一句跳转到对应时间；手动滚动或键盘浏览暂停跟随，可点击“回到当前歌词”恢复。右上角“无歌词”进入空态，并可模拟重新查找。
- 氛围歌词与待播：歌词以居中的三行文字浮在灯光中，待播清单用边缘渐隐的轻量列表呈现。开关与互切柔和淡入淡出，舞台画布、灯光投影和播放控件始终保持原位；快速反向切换从当前透明度续接。闲置时控制退去，歌词继续显示；关闭后的内容立即退出交互，Esc 与收起按钮将焦点还给对应入口。手机保留列表滚动、歌曲排序和移除，减少动态效果偏好跳过过渡。
- 底部播放器沿用原客户端胶囊：桌面居中磨砂胶囊、悬停进度和展开音量；手机为 52px 高度、32px 方形封面和黑色按钮。手机端通过左上角打开侧边栏切换页面，移除重复的底部导航；胶囊距底部安全区 12px，内容和提示同步预留间距。
- 桌面最小宽度为 480 CSS px，窄窗口使用原版紧凑胶囊；设备判断复用现有 `useMobileLayout()`。
- 键盘：⌘/Ctrl K 搜索、空格切换播放，滑条支持方向键。播放页的 Esc 优先收起歌词或队列，再次按下返回音乐库；其他弹窗可用 Esc 关闭。

建议体验路径：**登录 → 查看演示 → 首页 → 专辑 → 播放 → 打开沉浸播放器 → 待播清单 → 收起 → 歌曲更多菜单 → 添加到新歌单**。

## 原型边界

这是视觉和交互原型。配置本地曲库后，普通播放页、氛围模式和胶囊播放器都播放同一真实录音，由真实媒体时钟驱动进度、曲终事件与灯光。切换画面不暂停、不跳转、不重新准备音源，也不重建播放队列；仅切歌、清空当前曲目或显式重试才更换或重载音源。匹配不唯一或读取失败时明确报错，不使用其他录音代替。未配置曲库时，使用 38.4 秒原创合成循环 `public/audio/atmosphere-demo.wav`，并标注“原创演示音源 · 非本曲音频”。没有连接正式账号、扫描或数据库接口。使用示例用户名 `admin`（管理员）、`listener`（普通账号）、`newcomer`（首次登录）或 `quiet`（停用账号）。有效账号使用非空密码模拟登录，`wrong` 模拟密码错误；新密码表单验证长度与确认值，但不保存或发送凭据，因此原型不会验证后续登录是否匹配刚设置的密码。账号、会话、收藏、歌单与设置只保存在当前页面的内存中，刷新或进入其他预览场景会重置。正式服务的认证与数据库没有改动。

歌词使用本原型原创的 16 行示例文字，行时间点按当前曲目时长映射，用来体验排版、跳转和滚动；界面标注“原创演示 · 非本曲歌词”。显示规则与正式版一致：有逐词时间数据才逐词推进，只有行时间就按句切换，不均分句子时长或添加 CSS 进度延迟。原型尚未接入真实歌词服务，当前示例不包含逐词时间数据；播放真实曲目时以媒体时间定位示例行，未配置曲库时沿用模拟歌曲时间轴。

`src/library.json` 使用本地数据库的只读元数据快照：11 张专辑、1,054 首歌曲。不包含音频路径、凭据、数据库或音频文件。专辑中文名和示例歌单为原型展示文案，原始专辑名保留在详情页。歌曲格式以快照为准。

封面复制自已有的 `DATA_DIR/artwork` 缓存；复制前对记录推导出的源路径执行了 `safeRealPath`。当前首页主视觉直接复用专辑封面；早期照片素材保留在原型资源中。原型未修改音乐文件或真实收藏、歌单数据。封面权利属于相应作品的权利人，当前用于本地个人设计预览。

使用系统字体和项目已有的 Lucide 图标，未新增前端依赖。

## 本地真实音乐

在原型目录创建被 Git 忽略的 `.env.local`：

```dotenv
PROTOTYPE_MUSIC_ROOT="/path/to/music"
# 可选；必须位于音乐目录之外，默认使用仓库 artifacts/prototype-live-data
PROTOTYPE_DATA_DIR="/path/to/prototype-cache"
```

启动 `npm run prototype` 后，可以直接从普通播放页、专辑或歌单开始播放，也可以进入氛围模式点击「选曲」。两种模式使用相同的队列；从真实选曲面板播放队列以外的曲目时，沿用普通播放的追加规则。按原始专辑、曲名、碟/轨号与时长匹配快照曲目；录音始终只读，跳过符号链接。音频仅在本机解码与分析，不上传。ALAC 等格式用本机 FFmpeg 转成独立 AAC 缓存，首次播放需等待准备；兼容格式直接播放。无需修改正式服务配置。首次读取 1,054 首曲目的元数据也需要短暂等待。

每首歌生成可重复的灯光时间轴，跳转后定位相应灯光段落。编排规则升级后重新分析旧版本的时间轴，保留已有播放音频缓存；轻柔录音侧重双追光、光雨与铺色，较强低频、密集节奏和渐强可以触发水平光层、交叉光网与成组扫射。当前是基于声音特征的规则编排，不声称识别语义上的主歌、副歌或精确 BPM。分析失败时明确提示并使用实时频谱调度。原型限制单曲 45 分钟、两项并发准备，缓存定期淘汰旧内容（512 MiB / 约 24 首）。不要把缓存目录放入音乐目录，也不要将本地音频缓存打包发布。

- `src/catalog.css`：专辑、歌曲、收藏、歌单、搜索以及各类详情页的布局与响应式规则。

- `src/login.css`：登录入口的半透明面板、呼吸动画、表单和移动端布局。
